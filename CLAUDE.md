# Dharmastra project rules

- This is a web app that runs in the browser. No native or app-store builds.
- Mobile first: design for a 360px wide phone, then scale up. Touch targets are at least 44px.
- Meet WCAG 2.2 AA: contrast, keyboard use, visible focus, screen-reader names, reduced-motion, captions for audio, no color-only meaning.
- Everything is original. Never copy another game's name, characters, map or assets. Treat deities and sacred traditions respectfully.
- Mark every historical point as History, Tradition or Invented, with a year or "Legend".
- Missions are data plus script modules in `missions/`, built on the shared engine in `src/`.
- Run what you build before calling it done, and say plainly what was and was not tested.
- Never commit secrets or assets whose license forbids redistribution.
